# HireLog

A modern Job Application Tracker built with React and Tailwind CSS.

## Features

* Add Job Applications
* Edit Existing Jobs
* Delete Jobs
* Search by Company Name
* Filter by Status
* Filter by Priority
* Application Statistics Dashboard
* Local Storage Persistence
* Responsive Design

## Tech Stack

* React
* Vite
* Tailwind CSS
* JavaScript

## Installation

```bash
npm install
npm run dev
```

## Project Purpose

HireLog helps job seekers track applications, interviews, offers, and rejections in one place.
